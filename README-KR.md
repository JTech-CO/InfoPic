# InfoPic

[English](./README.md) | [한국어](./README-KR.md)

**브라우저에서 완성하는 정보성 카드뉴스.**

InfoPic은 인스타그램 스타일의 카드뉴스를 만드는 가벼운 편집기입니다. **표지 → 내용 → 후킹 → 브랜딩**으로 이어지는 기본 구성을 제공하며, 단일 HTML 파일로 실행됩니다. 별도의 백엔드, 계정, AI 서비스, 외부 API가 필요하지 않습니다.

## 주요 기능

- **카드 구성:** 표지 1장, 순서 변경이 가능한 내용 3~6장, 후킹 1장, 브랜딩 1장으로 구성됩니다. 세로형 **3:4**, **9:16** 비율을 지원합니다.
- **텍스트·브랜딩:** 4가지 텍스트 스타일, 정렬, 굵게·기울임, 로고, 표지 해시태그 최대 3개를 지원합니다. 선택한 텍스트의 글자색과 배경색을 기본 10색 또는 HEX 값으로 지정할 수 있습니다.
- **이미지 편집:** 이미지 맞춤·자르기·확대·축소·위치 조정, 밝기·대비·노출·채도 보정과 상단·하단·양쪽 비네팅, 불투명도를 조절하는 검정색 오버레이를 제공합니다.
- **출력·프로젝트:** 개별 PNG 또는 전체 ZIP 다운로드, 프로젝트 저장·열기, 실행 취소·다시 실행, 선택적 기기 백업을 지원합니다.
- **반응형 화면:** 데스크톱·태블릿·모바일에서 사용할 수 있으며, 한국어·영어 및 라이트·다크모드를 지원합니다. 기본 설정은 영어·라이트모드입니다.

## 시작하기

앱 HTML 파일의 이름을 `index.html`로 바꾸고 최신 브라우저에서 열면 됩니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

웹으로 배포하려면 `index.html`, `README.md`, `README-KR.md`를 레포지토리 최상위에 배치하고 해당 폴더를 GitHub Pages로 게시합니다.

## 개인정보·글꼴

앱은 텍스트·이미지·글꼴을 서버로 전송하지 않습니다. 환경설정과 선택적 자동 백업은 브라우저에만 보관됩니다. 장기 보관할 작업은 프로젝트 파일로 저장해 주세요.

다국어 텍스트는 기기에 설치된 글꼴을 사용합니다. 표시되지 않는 문자가 있다면 사용 권한이 있는 글꼴을 직접 불러올 수 있습니다.
